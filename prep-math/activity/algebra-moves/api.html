The endpoints

GET /api/algebra/parse
The tree a typed line becomes, every node with the id the animation matches on — and whether it reads back unchanged.
GET /api/algebra/moves
Every term, and the legal moves offered on it. The exact menu the page shows when you tap it.
GET /api/algebra/apply
Make one move. Terms are named by index, left to right across both sides, because node ids only mean anything inside one parse.
GET /api/algebra/solve
The whole worked solution. The solver has no powers a student does not — it picks from the same menu, one move at a time.
GET /api/algebra/check
Is that step legal? Works on any two lines, whoever wrote them. This is the gate every move passes before a student is allowed to see it.
GET /api/algebra/formulas
The formula shelf the page offers, with what every letter stands for and a worked set of values for each.

eq takes an expression as readily as an equation — leave the equals sign out and the moves on offer are the tidying ones. given pins a formula's letters to values (u:5,a:2,t:3), which makes the first moves substitutions.

How it is typed

Equations go in the way they are said — 1/2 for a half, x^2 for a square, 3x for three of them. In a URL, = must be written %3D and + as %2B; the box above does that for you.

Public on purpose: it is a pure function of its query string, capped at 200 characters in and 24 steps out.
