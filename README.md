# Spelling audio

Kokoro recordings of the Drills spelling bank, served to the site by jsDelivr. This branch
holds nothing else. It is written by `.github/workflows/spelling-audio.yml`: never edit it
by hand. `secondary/<voice>/NNNN-w|d|s.mp3` = word, definition, sentence of entry NNNN in
`data/spelling/secondary.js` (on the main branch).
